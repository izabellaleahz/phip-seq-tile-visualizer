# PhIP-seq Tile Library Visualizer

Interactive web app for exploring PhIP-seq peptide tile libraries — browse viruses, proteins, and tiles, with visualization of tile sharing across homologous proteins.

**Live site:** [https://izabellaleahz.github.io/phip-seq-tile-visualizer](https://izabellaleahz.github.io/phip-seq-tile-visualizer)

## Tech Stack

React + TypeScript, Tailwind CSS, Fuse.js, Vite, GitHub Pages

## Local Development

```bash
npm install
npm run dev
```
